# Personal Portfolio Website

A modern, responsive, and fully customizable personal portfolio website built to showcase my skills, experiences, and projects. 

## 🚀 Features

* **Modern UI/UX:** Clean and dark-themed design with aesthetic glassmorphism and gradient effects.
* **Fully Responsive:** Optimized for all devices (Mobile, Tablet, and Desktop).
* **Smooth Scrolling:** Seamless navigation between sections.
* **Sections Included:**
  * **Hero:** Eye-catching introduction with dynamic shapes and quick links.
  * **About:** Professional summary and educational background.
  * **Services:** Overview of the technical services I offer.
  * **Skills:** Categorized display of my technical stack.
  * **Projects:** Showcase of recent academic and professional projects.
  * **Contact:** Contact details and social media links.

## 🛠️ Tech Stack

* **Frontend Framework:** React.js
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Icons & Fonts:** Custom SVGs / Emojis / Google Fonts
